# Veyra AI — versione con API sicura
Chat React/Vite e endpoint server-side Vercel.

1. Sostituisci nel repository i file con quelli di questo ZIP, mantenendo `src/` e `api/`.
2. In Vercel → progetto → Settings → Environment Variables aggiungi `OPENAI_API_KEY` con la chiave privata. Facoltativo: `OPENAI_MODEL` con un modello disponibile nel tuo account.
3. Fai Redeploy. La chiave deve stare solo nelle variabili server Vercel, mai nel frontend o su GitHub.

Le API possono costare a consumo. Chiedi a un genitore/tutore prima di attivare fatturazione. Questa versione include chat e prompt suggeriti; non include ancora ricerca web, upload file, generazione immagini o account. Non si può garantire che sia migliore di Meta AI in ogni attività.
